# 邮箱助手 v2.3.9 · macOS 后端测试

本版将写信入口移到单个账号旁，支持多个发件账号块、选中后排队更新授权，以及“生成 CSV → 上传发件 → 发件历史”三步操作。保留邮箱域名自动发现与持久复用。未识别域名可在“本机数据 → 邮箱域名连接”配置一次；导入和联网验证分开。

适用于 Apple Silicon（M 系列芯片）、macOS 15 及以上。把“邮箱助手”拖到“应用程序”后打开。
应用使用本地签名，尚未经 Apple 公证；若系统阻止打开，在“系统设置 → 隐私与安全性”中允许打开已确认来源的应用。

## 核验真实接口

1. 首次启动会自动请求平台 `/api/external/account-credentials`，先加载约 20 个账号，其余后台继续。安装包不含账号数据库或邮件样本。
2. 进入“本机数据”，等待初始化完成后点击“下载接口检测报告”。报告列出平台请求的 UTC 时间、RequestId、HTTP 状态、页码、数量及本地实际记录数，不包含授权、邮箱地址、密码和邮件正文。
3. 在后端按 `X-Request-ID: mailbox-…` 对照同一条请求，区分平台账号接口、IMAP / Graph 邮件拉取以及本机网页请求。HTTP 200 表示收到成功响应头，初始化完成且数量一致才表示账号导入完成。
4. 搜索完整邮箱地址，或打开邮箱并刷新，验证实际邮件拉取。账号列表加载不等于邮件正文已下载，邮件直接通过服务商接口获取。
5. 可在“本机数据 → 网络策略”设置不可用的手动代理，点击“立即同步邮箱账号”验证失败提示；测试后恢复原网络策略。失败时历史缓存仍可显示，不代表本次请求成功。

已有用户数据的机器无需清空。需要完全独立的首次启动环境时，退出本次测试实例后使用：

```sh
cd /Applications
open -n --env "MAIL_ASSISTANT_DATA_DIRECTORY=$TMPDIR/mailbox-backend-test-$(date +%Y%m%d-%H%M%S)" --env 'MAIL_ASSISTANT_PORT=5149' '邮箱助手.app'
```

这会建立独立本地数据库和密钥，不更改正常使用的数据。若 5149 端口已被占用，可改为其他空闲端口。
本包不自动发送测试邮件，不修改平台账号授权。

## 下载与授权边界

交付仓库只提供安装包和说明，不发布租户授权源文件。授权随应用编译，不保存在明文 JSON 配置中。
公开二进制仍可被分析并提取授权；这不属于保密机制。公开下载意味着任何人都能取得该包内的授权。
