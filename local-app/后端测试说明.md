# 邮箱助手 v2.4.3 · Mac 验收

适用于 Apple Silicon（M 系列芯片）、macOS 15 及以上。拖入“应用程序”后打开；本包使用本地签名，尚未经过 Apple 公证。

1. 首次打开应直接显示本地邮箱。没有数据时，手动导入 CSV；不再等待平台初始化。
2. 从“本机数据 → 导入 CSV”导入账号。导入只保存，联网验证另行执行。同邮箱重复导入以最新凭据覆盖，不新增重复账号，不删除已下载邮件。
3. 打开任一已导入邮箱或刷新，直接连接邮箱服务商，不再显示“线上账号接口 HTTP 404”。未知邮箱需要先导入 CSV。
4. 后台验证运行时打开指定邮箱，手动查看应优先处理；如该账号正在后台验证，会取消后台验证让行。网络响应和服务器限流仍会影响实际耗时。
5. Outlook、GMX、Gmail 后台各 2 个，Yahoo 1 个，总计最多 8 个。同厂商别名域共享额度，限流后该厂商后台冷却 60 秒。

升级不需要清空本机数据。数据仍位于 `~/Library/Application Support/MailAssistant`。

独立测试实例（不会修改日常数据）：

```sh
cd /Applications
open -n --env "MAIL_ASSISTANT_DATA_DIRECTORY=$TMPDIR/mailbox-csv-test" --env 'MAIL_ASSISTANT_PORT=5149' '邮箱助手.app'
```

应用安装包不含用户数据库、邮箱凭据或平台 Token。邮箱凭据仅由用户 CSV 提供；邮箱服务商自身的 OAuth 令牌仍用于正常收发邮件。

本版导入结果只显示 CSV 导入成功或失败。点击“后台验证”后显示后台执行提示，不显示验证计数。打开邮箱优先验证并获取邮件。应用只跟随本机系统网络与 VPN，忽略应用保存过的手动代理。

“检查更新”读取 GitHub 签名发布文件，发现新版后自动下载、校验和重启。后台验证不会阻塞更新；正在写入 CSV 或发送邮件时等待当前操作完成。
