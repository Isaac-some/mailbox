# 本地账号与邮箱导入

本地版不再调用平台登录接口。登录账号来自 `appsettings.Local.json` 的 `LocalAccess.Accounts`；当前交付的两个账号是：

| 账号 | 密码 | 权限 |
| --- | --- | --- |
| `mail-reader` | `e30f60e238980e2cc930c93d` | 普通用户，只管理自己导入的邮箱 |
| `mail-admin` | `4d9c44295200d5a0db6a202e` | 管理员 |

`LocalAccess.ManifestUrl` 指向 GitHub raw 文件 `local-access.json`。应用每 5 分钟刷新一次；把某个账号的 `isActive` 改为 `false`，删除该账号条目，或把整个清单的 `enabled` 改为 `false`，已登录用户会在 5 分钟内退出，下一次登录也会被拒绝。GitHub 清单不保存密码或密码哈希。首次启动时若网络不可用，应用使用包内账号；成功读取过 GitHub 清单后，网络临时中断会沿用最后一次状态。

最高优先级标准格式固定为四列：`email,domain,credential,client_id`。`credential` 永远保存实际登录凭据；只有 Outlook OAuth2 才填写 `client_id`，Gmail、Yahoo、GMX 留空。导入页面仍兼容带额外列的 CSV，可识别“邮箱 / 邮箱地址 / email”等邮箱列，以及“IMAP授权码 / 授权码 / 应用专用密码 / 密码”等凭据列；授权码中的空格、换行和不可见字符会自动清理。导入只检查文件结构并保存，不连接邮箱服务器。打开邮箱或点击刷新时才连接 IMAP；认证被拒绝提示“授权码无效”，网络、代理、超时或服务器不可达提示“连接失败”。
