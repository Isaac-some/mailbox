# 邮箱助手 v2.3.6

首次打开自动初始化，约 20 个邮箱即可铺满第一页并开始使用，其余继续后台加载。知道完整邮箱地址时，可以直接搜索；系统优先检索授权并拉取该邮箱邮件，展示正在检索、拉取以及实际失败原因。

## 更新

- 初始化显示实际数量，首屏自动出现，无需手动刷新；全量导入实测从约 10 分半缩短至约 84 秒。
- 修复本地附件重新打开后内容丢失；刷新可补回远端仍保留的旧附件。预览、单独下载、ZIP 和 EML 导出均检查完整性。
- 回复邮件在应用内完成，自动填写收件人、主题和原文；修复空表单异常，拒绝不完整收件地址。
- 拉取、清理和诊断等操作显示工作状态；未经验证的账号明确标为待验证，改善状态文字和按钮可读性。
- 修复连接超时与取消传递，避免长时间无反馈；恢复出厂设置后自动重新初始化。

## 验证

744 项自动回归通过；4 类邮箱各抽 3 个进行真实连接，9/12 完成收件，另外 3 个分别为服务商限流或授权拒绝。Yahoo、Outlook、GMX 共确认发送 6 封带中文正文和附件的测试邮件。13 个页面、18 组交互验收通过。macOS 原生应用实际启动与恢复测试通过，恢复后约 5.3 秒重新铺满首屏。

网络及账号授权由各邮箱服务商控制；连接失败会显示实际原因。Windows 原生启动、附件实收与可读性最终复核结果将在封板时补齐。

## 下载

Windows x64：下载 ZIP 后完整解压，再打开“邮箱助手.exe”，保留同目录的 server 文件夹。macOS Apple Silicon：打开 DMG 后将“邮箱助手”拖到应用程序。

自动初始化安装包包含租户授权，下载统一位于[私有交付仓库](https://github.com/Isaac-some/mailbox-releases/releases/tag/v2.3.6)，需要使用有权限的 GitHub 账号登录。请勿转发到公开渠道。macOS 包使用本地签名，未经过 Apple 公证。
