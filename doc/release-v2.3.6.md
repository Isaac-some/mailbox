# 邮箱助手 v2.3.6 封板版

**v2.3.0–v2.3.6 累计更新说明**

这一版的核心体验：**打开自动同步，先用起来；知道邮箱地址，就能直接查。** 同时汇总这段版本的桌面小窗、批量导入、邮件阅读、收发与附件修复。

## 下载安装

- **[Windows x64 · 直接下载 ZIP](https://github.com/Isaac-some/mailbox-releases/releases/download/v2.3.6/MailAssistant-Windows-x64-v2.3.6.zip)**：完整解压后打开“邮箱助手.exe”，保留同目录的 server 文件夹。
- **[macOS Apple Silicon · 直接下载 DMG](https://github.com/Isaac-some/mailbox-releases/releases/download/v2.3.6/MailAssistant-AppleSilicon-v2.3.6.dmg)**：适用于 M 系列芯片 Mac，打开后将“邮箱助手”拖到“应用程序”。

安装包存放于私有交付仓库，点击下载前需登录有访问权限的 GitHub 账号。macOS 安装包使用本地签名，尚未经过 Apple 公证。

## 1. 自动同步：打开即可开始使用

- **首次打开自动初始化**：自动从平台拉取邮箱账号及授权信息，无需手动导入或点击同步。
- **先铺满第一页**：约 20 个邮箱账号信息到位后即可开始操作，其余账号继续在后台加载，不必等待全部完成。
- **进度看得见**：界面提示正在初始化、检索或拉取，并显示已加载的实际数量；连接失败时说明原因。
- **重启继续更新**：后续打开会自动检查并同步平台账号信息；恢复出厂设置后也会重新开始初始化。

这里的首屏初始化指邮箱账号列表；邮件内容会在搜索、打开邮箱或刷新时按需拉取。

## 2. 优先搜索：邮箱还没显示，也能直接找

- 输入**完整邮箱地址**，即使该邮箱尚未出现在当前列表，也会优先向平台检索账号和最新授权信息，再拉取该邮箱的邮件供查看。
- 搜索和单个邮箱刷新优先处理，不必排在全量初始化之后；刷新时先检查最新授权，再拉取邮件。
- 后台全量同步与单个邮箱的优先请求协调执行，减少重复拉取与等待。

## 3. 桌面体验：小窗、置顶与阅读更顺手

- macOS、Windows 均支持桌面模式与手机尺寸的小窗模式，小窗默认约 420 × 860，可自由调整大小。
- 支持窗口置顶；分别记住两种模式的窗口大小及置顶状态，重启后恢复。
- 切换模式保留当前搜索、邮箱和邮件阅读状态；Windows 窗口适配屏幕可用区域与缩放比例。
- Windows 快捷键：`Ctrl + Alt + M` 切换小窗，`Ctrl + Alt + P` 切换置顶。
- 小窗中点击邮件进入完整详情，返回时保留邮箱、分类、搜索条件和页码；宽窗口保留列表与详情并排阅读。
- 邮箱卡片、操作按钮、搜索栏及长邮件内容适配窄窗口；导入、导出及账号操作的按钮文字更清楚。

## 4. 账号管理：批量导入与授权验证分开进行

- 批量导入支持标准表头、中文别名、无表头文本及多种分隔符。
- 统一识别 Gmail、Yahoo、GMX、Outlook / Microsoft 和自定义域名；按服务商规则处理授权信息。
- 账号加密保存后，可单独启动后台验证；通过任务浮层查看进度与失败原因，支持只重试失败账号。
- 按服务商控制验证并发、处理限流；重复导入同一邮箱可更新授权并重新验证。
- 未验证账号明确显示“待验证”，避免把保存成功当成连接成功。

## 5. 邮件与附件：时间准确，导入、回复和下载更可靠

- **修正邮件时间**：收件优先使用可信的最终到达时间，分别标明“到达时间”和“发送时间”；兼顾服务商时间偏差，减少近期邮件漏查，并修复可可靠校正的历史记录。
- **应用内回复**：自动填写收件人、主题及原文；修复空表单异常，对不完整的收件地址给出提示。
- **附件保存与恢复**：修复重新打开后本地附件内容丢失；远端邮件仍保留时，可通过刷新补回旧附件。附件预览、单独下载、ZIP 打包与 EML 导出均检查完整性。
- **本地邮件导入**：修复 MBox / EML 导入与跨时区重复识别；导入本地文件无需等待远程文件夹加载。
- **运行与安装稳定性**：改善连接超时、取消和操作状态提示；Windows ZIP 使用 UTF-8 文件名，避免中文启动文件名乱码；优化打包流程与发布目录，减少安装包混入无关文件。

## 验收结果与已知限制

- **745 项自动回归通过**；13 个主要页面、22 组交互验收通过；5 个主要页面的无障碍自动检查未发现违规。
- 4 类邮箱各抽取 3 个进行真实连接：**9 / 12 完成收件**；其余 3 个遇到服务商限流或授权拒绝。
- Yahoo、Outlook、GMX 共确认发送 **6 封**带中文正文和附件的测试邮件，其中 **5 封确认实收**；11 份收发副本附件实际下载后校验一致。另 1 封仅确认发送成功，未确认到达。
- 隔离环境的全量账号初始化实测由约 **10 分半缩短至 84 秒**；macOS 恢复出厂设置后，实测约 **5.3 秒显示首批 20 个邮箱**。耗时随网络和平台响应变化。
- macOS 原生启动与恢复测试通过；Windows 独立 CI 的原生启动、内置运行环境、隔离数据库初始化及桌面回归通过。上述交互验收使用 macOS 本机浏览器运行同一套页面，未完成 Windows 原生逐项人工交互验收。

服务商限流、授权失效或邮件投递延迟仍可能影响收发；界面会展示已识别的失败原因。
