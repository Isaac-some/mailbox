# 邮箱助手 v2.4.3 验收记录 · 2026-11-18

## 行为

- CSV 导入任务和验证任务状态分离。右下角只显示 CSV 保存成功与导入失败；导入结果页不包含认证、TLS、限流或待验证统计。验证错误不会增加导入失败数，也不会污染 CSV 失败明细。
- 点击“后台验证”提示“已在后台执行自动验证。直接打开邮箱将优先验证并获取邮件。”后台计数保留在内部。打开指定邮箱使用独立交互通道，并取消该邮箱正在进行的后台验证。
- 桌面应用跟随当前设备系统网络/VPN，忽略旧 network-settings.json 中的独立代理。维护页不再提供单独代理配置。发布物排除用户网络、域名配置、数据库、密钥及失效平台 Token。
- 检查更新来自 Isaac-some/mailbox-releases 最新正式 Release，自动下载、验签、重启安装。后台验证不阻塞升级；实际 CSV 写入或发件完成后再安装。GitHub 网页资产路径超时或出错时，备用路径使用官方 API 的固定仓库资产 ID；无内置 GitHub Token，签名及 ZIP 哈希校验照常执行。
- 延续 CSV 覆盖导入、线上账号拉取关闭、厂商后台并发和限流退避。
- DMG 只放“邮箱助手.app”和 Applications 拖拽入口，不放后端测试文档。Windows 交付包含外壳、后端和运行时的单个完整安装 EXE。
