# v1.0.20 平台账号登录改造说明

此版本的本地开发代码已切换为平台账号登录方案，发布版本号待下一次打包时提升为 `1.0.21`。

- 启动后强制显示登录页，不再自动注入本地随机账号。
- 登录请求发送到 `https://openrouter.tuchong.com/api/auth/login`。
- 会话 Cookie 或 Bearer Token 只在当前进程内存中保存，不写入安装包或本地连接配置。
- 普通用户和管理员由平台账号角色决定；平台账号停用后，邮箱接口的 `401/403` 会清除会话并要求重新登录。
- 邮箱接口继续使用 `GET /api/external/account-credentials` 的 `data.total/items/serverTime` 响应结构和增量游标。

平台研发需要确认登录成功返回会话方式、邮箱接口接受的鉴权方式、停用账号返回 `401/403`，以及角色字段 `role` 或 `isAdmin`。详见《平台账号登录接入说明.md》。

验证：Release 编译通过，0 错误；平台同步与连接存储专项测试 6 个通过，0 失败；Windows x64 构建通过。macOS DMG 需要在具备磁盘映像设备的构建机上生成。
