# 首次使用与真实收发验收（2026-10-15）

## 目标

首次启动自动获取邮箱授权，约 20 个邮箱即可铺满第一页并开始使用，其余后台继续加载。用户输入完整邮箱地址时，即使本地没有该账号，也应优先检索授权、拉取邮件，并看到明确的进度与失败原因。

## 隔离与范围

- 使用独立 SQLite、密钥、同步游标和日志目录，不清空现有数据。
- 从实际平台记录按服务商抽样，每种尽可能 3 个；样本不足如实记录。
- 测试邮件只发送给抽样账号，使用本次唯一标记；不删除真实邮件，不修改平台凭据。
- 原始证据保存在忽略的 `.runtime/acceptance-20261015/`，本报告不含地址、凭据和邮件内容。

## 验收矩阵

| 范围 | 必须验证 |
|---|---|
| 新安装 | 空库启动、服务响应、自动拉取、初始化提示、首屏 20 条、无需手动刷新 |
| 精确搜索 | 未导入账号、后台导入过程中优先查询、授权和邮件自动拉取、大小写和空格 |
| 查看邮件 | 收件/已发送、正文、附件、分页、刷新、无邮件的明确状态 |
| 真实收发 | 每种可用服务商抽样连接、跨账号互发、收件端实际收到、已发送归档、附件完整性 |
| 接口故障 | 无权限、超时、500 重试、格式错误、空数据、分页中断、游标恢复、重复导入 |
| 并发 | 搜索不等全量、重复操作去重、旧授权不覆盖新授权、交互任务优先 |
| 回归 | 全套 .NET（隔离 PostgreSQL）、SQLite、页面脚本、浏览器操作、辅助服务测试 |
| 交付边界 | macOS 本机原生启动与重置；Windows 独立 CI 验证原生启动；同一页面浏览器交互验收 |

## 实测结果

- 自动回归：745 项 .NET 测试全部通过（含隔离 PostgreSQL、SQLite 附件重启与 EML 字节校验、本地导入与跨时区去重）；辅助服务 6 项测试与类型检查通过。
- 首次初始化：真实平台共 14,299 条，导入 14,298 个有效账号，跳过 1 条格式错误；全量导入从 629.78 秒降至 83.94 秒。页面先显示 20 个邮箱，其余后台加载。
- 优先搜索：对未显示账号进行完整地址检索，9 个可用样本的检索响应约 0.17–0.47 秒并进入优先邮件拉取队列；错误、超时和账号不可用分别显示，数量进度按实际导入数据计算。
- 原生恢复：macOS 实际应用包在隔离目录启动；取消恢复保留数据，确认后密钥重新生成、服务自动重启，5.333 秒恢复首屏 20 个账号。现有用户应用和数据未清理。
- 真实收件：Gmail、Yahoo、GMX、Outlook 各抽 3 个，共 12 个。9 个完成；3 个外部问题为 Yahoo 限流 1 个、Gmail 与 Outlook 授权拒绝各 1 个。复核中另遇 Gmail/GMX 网络波动，超时如实显示，不能保证所有样本随时可连接。
- 真实发送：6 封带中文正文和附件的邮件获得服务商发送成功确认，覆盖 Yahoo、Outlook、GMX。收件端确认 5/6 封实际到达；11 份本地副本（6 份已发送、5 份实收）的附件经 HTTP 下载后 SHA-256 均与原附件一致。剩余 1 封 Outlook → Yahoo 仅确认发送成功，未宣称实收通过，也未重复发送。
- 页面与表单：13 个主要页面正常返回，无脚本错误；10 组查看/校验、8 组实际写入/清理、4 组扩展操作通过。覆盖搜索、分页、服务商识别、空表单校验、站内回复、代理表单、诊断输入、发件人选择/导出、新增/编辑/删除、CSV 导入进度、未来定时任务创建后取消、附件预览/单独下载/ZIP/EML、清空取消与确认。扩展覆盖启用/禁用、同步时间编辑/重置、本地 MBox 导入和整账号 EML ZIP 导出下载。
- 可读性：390px 窄窗无横向溢出；调整按钮和状态文字对比度，给列表操作添加文字，将“进口/出口”误译改为“导入/导出”；实际数量代替虚构进度。5 个主要页面的 WCAG 2A/AA 与 2.1AA 自动检查未发现违规。
- Windows：独立 Windows CI 的桌面回归、完整打包、原生启动、HTTP 首屏、隔离 SQLite 与初始化状态验证通过。交互测试使用 macOS 本机浏览器运行同一套页面；未宣称人工操作过 Windows 的每个窗口。

## 修复的根因

1. 首次接口请求等待大页数据，首屏缺少自动刷新：先拉 20 条，再按固定分页重头扫描，避免换页大小跳过账号。
2. 批量导入保留全部已处理对象导致保存越来越慢：后台独立上下文在每次成功保存后释放跟踪。
3. SQLite 未使用 PostgreSQL 专属的附件去重拦截器，内容仅暂存在内存：为 SQLite 持久保存附件字节；刷新可修复仍在远端保留的旧空附件；不完整附件阻止空文件下载并提示重新拉取。
4. 连接取消未覆盖全部路径：对连接与后续能力检测传递取消信号。实测部分网络连接接近 50 秒，交付包连接上限设为 60 秒。
5. SQLite 本地文件导入使用不可翻译的时间差计算导致整封导入失败：改为统一存储时区的上下界比较，新增跨时区去重回归测试；本地导入不再等远程文件夹加载。
6. 回复跳出应用、空主题引起异常、无域名收件地址被误当作有效地址：补齐站内回复和服务端输入校验。
