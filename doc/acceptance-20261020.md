# macOS 后端测试包验收 · 2026-10-20

- 404 已在未登录请求中复现，原因是交付仓库为私有仓库；与公司内网限制无直接关系。按用户要求公开交付仓库，仓库内容仅为安装包和说明。
- v2.3.7 授权由私有临时源码编译进程序，生成文件构建后清理；包内 JSON 的 Token 为空。源码、数据库、密钥和邮件样本未打入 DMG。公开二进制可被分析并提取授权，此限制已向用户说明。
- 最终 .NET 回归 745 项全部通过；页面脚本回归通过。最初 746 项基线包含一项临时网络探针，探针通过后移除，不能据此将最终结果写成 746 项。
- 实际 v2.3.7 原生应用使用独立空数据目录启动，约 10.4 秒时已可使用首屏；平台声明 14,399 条，实际导入 14,398 个有效账号、跳过 1 条无效记录。整个过程没有预置账号数据库。

- 新增报告的 16 次真实平台请求均为 HTTP 200，包含唯一请求编号；同一编号通过 `X-Request-ID` 发给平台，可供后端核对。时长统计截至收到响应头，报告另行标记完整初始化是否失败。
