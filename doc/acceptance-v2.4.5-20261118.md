# v2.4.5 Outlook 收件修复验收

个人 Outlook 使用已授予的 Microsoft Graph 邮件权限读取 `/me/mailFolders/.../messages`，授权交换请求 `.default offline_access`；不要求另授予用户资料权限。Graph 无收件权限时回退原有 IMAP，网络故障、服务故障和限流不会触发另一轮登录。成功的 IMAP 路由临时缓存，凭据变更会重新尝试 Graph。

后台验证与实际收件共用同一路由。Graph 收件与发件、IMAP 的访问令牌分别缓存，刷新令牌轮换持久化。邮件列表请求批量包含正文，优先保存当前文件夹；页面在其他文件夹继续收取时即可展示已落库邮件。

修复桌面 SQLite 无法翻译原 Graph 去重日期相减表达式、异常后误把新邮件当成重复邮件的问题。查询改为时间上下界比较，去重异常明确失败，不再静默跳过。网络连接池按当前设备代理隔离复用；不携带构建机网络设置，也不共享 Cookie。

## 实测

对用户报告的 Outlook 账号做隔离测试，只读读取日常配置，测试数据写入临时数据库。原版可复现 IMAP 认证失败；新生产路由取得近 7 天的 6 封邮件，6 封正文均保存，验证成功，第二次收取后仍为 6 封。完成后删除临时数据库；未修改日常账号、未发送邮件、未改变服务端已读状态。

自动回归覆盖真实 Graph SDK 的收件权限验证、401 单次刷新、权限失败回退、网络错误不回退、邮箱级 Retry-After、受限分页、收件令牌独立缓存、SQLite 正文和日期持久化、优先文件夹保存、重复刷新以及 HTTP 连接复用。安装包的二进制版本、源提交和哈希由 `script/verify-desktop-release.py` 验证；GitHub 发布是独立步骤。
