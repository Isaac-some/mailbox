# 邮箱助手 v2.4.1 · 邮箱连接提示优化

优化收件、发件时的 VPN/代理连接错误提示：明确提醒当前节点可能无法连接该邮箱域名的收发端口，建议切换节点后重试；代理拒绝连接时，提示检查节点的端口限制。

TLS 连接失败仍可能与服务器地址、端口、加密方式或证书有关，提示中保留相应排查入口。

## 更新方式

v2.4.0 用户可在应用内点击“检查更新”，下载后选择“重启并更新”。账号、邮件和本机设置保留。

v2.3.9 及之前版本需要手动安装一次支持应用内更新的版本。

- [macOS Apple Silicon DMG](https://github.com/Isaac-some/mailbox-releases/releases/download/v2.4.1/MailAssistant-AppleSilicon-v2.4.1.dmg)
- [Windows x64 ZIP](https://github.com/Isaac-some/mailbox-releases/releases/download/v2.4.1/MailAssistant-Windows-x64-v2.4.1.zip)

Mac 更新 ZIP 由应用自动使用，手动安装请下载 DMG。macOS 沿用本地签名，尚未经过 Apple 公证。
